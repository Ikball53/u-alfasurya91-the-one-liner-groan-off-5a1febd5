# The One-Liner Groan-Off

A single original dad joke, one line, written by `main.py` to `/output/entry.txt`.

Run with Python 3.13 (stdlib only, no network, deterministic):

```sh
python3 main.py
```

Output: one line, 1–140 characters, UTF-8.
